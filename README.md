## 🚀 Projeto em destaque

### AU FOOD

Aplicação para gerenciamento de uma loja fictícia de produtos para pets, desenvolvida utilizando **ServiceNow App Engine Studio**.

No projeto trabalhei com:

- Cadastro de produtos, estoque e pedidos;
- Relacionamentos entre tabelas;
- Importação de dados via Excel;
- Categorias e subcategorias dependentes;
- Controle de acesso por funções;
- Automação de processos com Flow.

[Conheça o projeto AU FOOD](https://github.com/arthur-peres-souza/au-food-servicenow)
